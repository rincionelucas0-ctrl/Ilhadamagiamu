ILHA DA MAGIA PWA — VISUAL v3

1. Subí el contenido de este ZIP a Netlify como sitio HTTPS. index.html, manifest.webmanifest, sw.js y la carpeta icons deben quedar juntos en la raíz.
2. Abrí la URL pública desde Chrome en Android. Tocá el menú ⋮ > Instalar aplicación (si aparece) o Mi perfil > Instalar aplicación.
3. En iPhone, abrí la URL en Safari y usá Compartir > Agregar a pantalla de inicio.
4. No abras index.html desde la carpeta Descargas: content:// y file:// no habilitan la instalación PWA.
5. El servicio offline solo guarda la estructura HTML. Las publicaciones Supabase, mapas y bibliotecas externas necesitan Internet.
6. No incluye ADMIN para no publicar inadvertidamente el panel privado. ADMIN no se modifica.
